# CP3 — Body Map: визуальный референс (источник истины)

Референс предоставлен Анной 2026-09-16 (скриншот экрана «Замеры» из другого приложения).
НЕ заменять произвольным силуэтом/абстрактной схемой. Старая самодельная body map НЕ считается
выполнением CP3.

## Что на референсе
- Реалистичный 3D-манекен женской фигуры, фронтальный вид, серый матовый рендер.
- Тёмный фон. Зелёные (акцентные) горизонтальные линии-обхваты на уровнях:
  шея, плечи, грудь, бицепс, талия, бёдра (hips), бедро (thigh).
- Подписи — тёмные «пилюли» (название зоны + значение), вынесены вбок линиями-выносками.
- Нижний таб-бар: Дневник · Аналитика · Замеры · Рецепты + круглая «+».

## Визуальный принцип, который надо повторить в AGHealth
1. Анатомичный ЧЕЛОВЕЧЕСКИЙ силуэт (не набор прямоугольников/абстракция).
2. Мышцы/зоны расположены на теле реалистично.
3. Возможность визуально показать степень нагрузки (высокая/средняя/низкая/нет)
   подсветкой соответствующей зоны — по аналогии с зелёными акцентами референса.
4. Интерактивность: тап по зоне мышцы.

## Отличие от референса (наша задача)
- Вместо обхватов в см — подсветка мышц по нагрузке из единого muscle-load слоя.
- Front + back виды.
